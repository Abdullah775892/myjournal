# نشر الكراسة الرقمية (PWA) على Render

التطبيق موقع ثابت (Static Site) مجاني على Render، ويعمل بعدها بدون إنترنت بعد أول زيارة، وتُحفظ بياناتك على جهازك.

## 1) ارفع المشروع إلى GitHub
1. أنشئ مستودعاً جديداً (Private أو Public) في github.com.
2. ارفع كل محتويات هذا المجلد كما هي (index.html و sw.js و manifest.webmanifest و build.sh و render.yaml والأيقونات).
   - من سطر الأوامر:
     ```
     git init && git add . && git commit -m "notebook"
     git branch -M main
     git remote add origin https://github.com/<حسابك>/<المستودع>.git
     git push -u origin main
     ```

## 2) أنشئ الموقع على Render
1. ادخل https://dashboard.render.com وسجّل بحساب GitHub.
2. اضغط **New +** ثم **Blueprint** واختر المستودع، فيقرأ `render.yaml` تلقائياً ويضبط كل شيء.
   - أو يدوياً: **New + → Static Site** ثم:
     - Build Command: `sh build.sh`
     - Publish Directory: `dist`
3. اضغط **Deploy** وانتظر دقيقة. ستحصل على رابط مثل `https://digital-notebook.onrender.com`.
   - المكتبات (PDF.js و Dexie و jsPDF) والخط IBM Plex تُنزَّل تلقائياً أثناء البناء، فلا ترفعها يدوياً.

## 3) ثبّت التطبيق على جهازك
- **ويندوز/ماك/لينكس (كروم أو إيدج):** افتح الرابط ثم أيقونة التثبيت في شريط العنوان، أو زر «⤓ تثبيت» داخل التطبيق.
- **أندرويد (كروم):** القائمة ⋮ ثم «تثبيت التطبيق».
- **آيفون/آيباد (سفاري):** زر المشاركة ثم «إضافة إلى الشاشة الرئيسية».
بعدها يعمل من الشاشة الرئيسية بدون شريط المتصفح وبدون إنترنت.

## 4) تحديث التطبيق لاحقاً
عدّل الملفات وارفعها إلى GitHub (`git push`) فيعيد Render النشر تلقائياً، ويأخذ المستخدمون النسخة الجديدة في الفتح التالي (رقم نسخة الكاش يتجدد مع كل نشر).

## ملاحظات مهمة
- بياناتك (كراساتك وملفات PDF) تُحفظ في IndexedDB داخل المتصفح على كل جهاز، ولا تنتقل لـ Render ولا تتزامن بين الأجهزة. خذ نسخة احتياطية دورية بزر 💾 (ملف .inknb.json) وافتحها في جهاز آخر بزر «🗂 فتح».
- لا تمسح «بيانات الموقع» من إعدادات المتصفح وإلا تُحذف الكراسات (التطبيق يطلب «تخزيناً دائماً» لتقليل هذا الاحتمال).
- النسخة المجانية من Static Sites لا «تنام» ولا تتأخر، بخلاف الخدمات الديناميكية.
- للتجربة المحلية قبل الرفع: `sh build.sh && cd dist && python -m http.server 8080` ثم افتح http://localhost:8080
- لو فشل تنزيل الخط أثناء البناء يظهر تحذير فقط ويعمل التطبيق بالخط الاحتياطي.
